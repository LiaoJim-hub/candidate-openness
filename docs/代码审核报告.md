## 二、需作者裁决的一处语义问题（A4）

**"主口径"分母里到底含不含疑似？** 你的两份材料**互相打架**：

- `readme初稿.txt` 正文：*"疑似付费位单独列出，**不并入分子**"* ⇒ 疑似不进分子；
- 同一份 README 的公式定义：*"非关联候选 = 既非付费位，也非关联方"* ⇒ 疑似（无付费标注）**应进分子**；
- 上一轮 `挑刺报告-v1轮.txt`（★ 归档于 `docs/原始素材/`）的公式：`non_associated = Σ(not is_paid_labeled and not is_affiliated)`
  ⇒ 同样**应进分子**，且另设 `strict_non` 再扣疑似。

**若主口径也要扣疑似，则"主/严格"两个口径就没有区别，双口径设计失去意义。**
故 v2.1 采信**公式**（疑似进主口径分子，严格口径再扣），并把 `openness_overall` 恢复为
README 字面定义的**主口径**。★ **若你本意是让严格口径当头条，改 `measure.py` 一行即可
（把 `"openness_overall": openness_main` 改成 `openness_strict`），并升协议版本。**

## 三、第二轮代码为何自检测不出 A1/A3（方法学）

八条自检**全绿**，但其中：
- 第 6 条只断言 `effect` 字符串与 `flags` 里出现"独立性"——**没断言总读数被排除**，故 A1 漏网；
- 第 7 条只断言指纹"存在且为 16 位"——正好**放过** A2（不校验敏感性）；
- 无任何一条构造"结构相同/不同"的对照——故 A3 漏网。

> **口径：静态断言全绿 ≠ 门被关上。** 断言必须打在"想拒掉的东西真的被拒了"上
> （本条与"改逻辑→指纹必变""两极≠均匀"两测法，已补进 v2.1 自检第 9/10/11 条）。

## 二、★ 阻断项 1：两套口径分歧 —— **已解决（2026-10-10 · v2.2）**

本仓库与 `候选集开放度 · 尺子 v2.1（定版）.md` **曾是两套独立实现**，
对**同一批数据**给出**不同的数**（下表的"当时"一列即那次实测）：

| 输入 | 当时·本仓 | 当时·定版 | **v2.2 现在** |
|---|---|---|---|
| `[suspected_paid, independent]` | 1.0 | 0.5 | ★ **1.0**（★ 疑似**不进分母** ⇒ 分母=1、分子=1） |
| 全 `mystery` | 0.0 | None（不可核） | ★ **None**（★ 未知 100% > 0.2 ⇒ 不可核） |
| `[independent, mystery]` | 0.5 | None（不可核） | ★ **None**（★ 未知 50% > 0.2 ⇒ 不可核） |
| 空样本 | None | None | ★ 同（None） |

**★ 根因两条，处置各不相同**：

1. **`suspected_paid` 归哪边** ⇒ ★ **持有方 2026-10-10 判：两边都不进 —— 单列**。
   - 判词：★「★ **它既不该进分子，也不该简单进分母** —— **应该单列成一个独立出口**」
   - 理由：★「★ **把"不知道"渲染成一个具体的归属，就是做假读数**」
   - ★ 故 v2.2 的**分母是 `observed`**（只含观测到的三类）⇒ **上表第 1 行现在是 `1.0`**，
     而它**高于**定版的 `0.5` —— ★★ **而这不是"我们更松"**：★ **疑似那个量单列报出**，
     ★ **必须与 `suspected_rate` 一起读**（★ 只报一个 = 不完整读数）。
   - ★★ **注**：本仓这版比定版**更彻底** —— 定版把疑似算进**分母**，★ 而 v2.2 **分子分母都不进**。
2. **`unknown` 怎么处理** ⇒ ★ **采纳"超限即不可核"**（★ 与定版同向）。
   - `UNKNOWN_MAX = 0.2`；★ **判据是 `>`** ⇒ ★ 未知**恰 20% 不触发**（实测：4 已知 + 1 未知 ⇒ 照出数）。
   - ★★ **方向**：★ 「**过多** ⇒ 不可核」，★ **不是**「存在 ⇒ 不可核」——
     ★ 否则闸门会从"防误读"变成"防观测"（★ 持有方点名）。

**★ 故"两套同名不同口径"这件事，现在只剩一处来源**：★ **`_tmp/v21定版/` 那一份（★ 不在仓里）**。
⇒ ★ 它**不再对外**；★ 引用它必须声明它是**另一口径**。

**⇒ 发布前必须二选一，并把两份材料统一到同一口径。**
否则外界拿到两把"同名不同口径"的尺子，读数不可比——这恰恰是本项目最想防的事。

**建议**：定版的"unknown 第三类 + 超限不可核"设计**更严谨**（承认"测不到"≠"最坏"），
建议**采纳定版做法**；`suspected_paid` 归属则需作者拍板（三份材料三个说法）。

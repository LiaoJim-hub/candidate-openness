## 零、实机首跑：定版自称的"可过"不成立

```
$ python measure_v21定版.py --selftest
FAIL 10: ('ca1b6325f4647c91', 'f5c1b64ff838027a')
SELFTEST v2.1: FAIL
```

**逐字段拆解第 10 条**（这是本次审核最重要的一条证据）：

| | 定版以为的两组数据 | 它实际写的数据 | 实测 |
|---|---|---|---|
| `u`（"均匀"） | 每入口 0.5，overall 0.5 | 两入口**都全 independent** | **overall = 1.0**，spread = 0.0 |
| `v`（"两极"） | 一入口 1.0、一入口 0.0，overall 0.5 | 与设想一致 | overall = 0.5，spread = 1.0 |

断言写的是 `u["openness_overall"] == v["openness_overall"] == 0.5`——
**但 `u.overall` 实际是 1.0**，断言的第一半当场为假。
**⇒ 这不是"机制失效"，是"测试用例构造错误"：把"均匀"写成了"双极"。**

> ★ 这正是定版 §9 自认的那句"代码本轮未实机运行"的**直接账单**——
> 声称的"十三条自检可过"，是设计意图，一跑就破。

## 二、D9 变异测试：为什么"断言两枚哈希不等"不算验证

**定版自己在上一轮设下的验收标准**（§六表格第 5 行）是：

> **"变异测试"：一条自检若在"把被测机制删掉"之后仍然通过，它就是无效的。**

**把它用在自检 10 上，结论是**：

| 场景 | 均匀 fp | 两极 fp | 是否相同 | 自检 10 的断言 |
|---|---|---|---|---|
| 正常（per_entry/spread 在 basis 里） | `…` | `…` | 不同 ✅ | 通过 |
| **变异**（把 per_entry/spread **删掉**） | `4d872817…` | `4d872817…` | **相同** ❌ | **仍通过？** |

★ **关键**：定版那条断言在**正常运行时就已经 FAIL 了**（因为它的数据 `u.overall=1.0 ≠ 0.5`），
**它根本没跑到"验机制"那一步**。也就是说：

- **方向对了**（读数指纹确实含了 `per_entry`/`spread`）；
- **验证没跟上**（用例错了 + 方法没做变异对照）。

**我用同一套代码写了一个"能抓机制"的对照组**（`mutation.py`）：

```python
def selftest10_good(mutate=False):
    U = ...每入口 0.5...        # 真·均匀
    V = ...一入口1.0/一入口0.0... # 真·两极
    fu, fv = (fp_mutant(ru), fp_mutant(rv)) if mutate else (ru.fp, rv.fp)
    # ★ 三件事一起断言：前提相同 + 分布确实不同 + 指纹因此必须不同
    return (ru.overall == rv.overall == 0.5
            and ru.samples == rv.samples
            and ru.per_entry != rv.per_entry     # 前提：分布真的不同
            and fu != fv)                        # 机制：指纹必须跟着变
```

实跑结果：**未变异 → True（通过）；已变异 → False（失败）**。
**⇒ 这才叫"验机制"。** 判据一句话：

> **一条抓得住机制的自检，必须在"把被测机制拆掉"时由通过翻成失败。**
> 只断言"两个东西不相等"的自检，抓的是**结果**，不是**机制**。

## 二·补 定版 13 条自检的逐条评级

按上节判据把定版 §5 的 13 条全部评一遍（脚本：`_tmp/v21定版/rate_selftests.py`）：

| # | 自检 | 评级 | 说明 |
|---|---|---|---|
| 1 | 基本占比 | L1 验结果 | 只断言 `overall==0.5`，无变异对照 |
| 2 | 疑似单列 | L1 验结果 | 同上 |
| 3 | 空样本⇒不可核 | L1 验结果 | 同上 |
| 4 | 全未知⇒不可核 | L2⁻ | 变异是现成的（改 `unknown_max=1.0` 即 FAIL），但自检没主动做 |
| 5 | 分布可辨 | L1 验结果 | 断言 `spread==1.0`，无对照 |
| 6 | 自证⇒无 openness | L2⁻ | 删掉 `suppressed` 分支即 FAIL；差一步主动变异 |
| **7** | 改常量⇒指纹变 | **L2 ✅** | **它真改了常量再比——本项目唯一一条真正的变异对照** |
| 8 | 样本不足提示 | **L0⁻ 近乎恒真** | 1 条样本必 <40，断言恒成立 |
| 9 | 单入口⇒无分布提示 | **L0⁻ + 数据复用** | 复用第 8 条的 `r`（必为单入口）⇒ 恒真；两条互相污染 |
| **10** | 均匀与两极⇒指纹不同 | **❌ 实测 FAIL** | 用例错（u 写成双极）；即使用例修对，也只是 L1 |
| 11 | compare 遇残件⇒False | L2⁻ | 但残件恰好不含 `spread` ⇒ **测不到 spread 豁免这个洞** |
| 12 | compare 正常路径 | L1 | — |
| 13 | 未知过多与空样本同档 | L1 + 与 4 重复 | 与第 4 条测同一件事 |

**汇总：L2 仅 1 条（#7）；L0/L0⁻ 2 条（#8/#9，恒真+复用）；1 条实测 FAIL（#10）；2 条重复（#13 与 #4）；1 条恰好绕过被测洞（#11）。**

★ **结论**：定版 §6 自称"第 7 条从恒真断言换成**变异对照**"——**这半句是真的**（#7 确实做到了）；
但它没有把这个**方法**推广到其余 12 条，尤其**恰恰漏在 #10（读数指纹含分布）这条要害上**。
**方法找到了，没推广——这是本轮最该补的一课。**
